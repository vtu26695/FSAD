# Inventory Control Dashboard

A clean React + Vite application for relational inventory management and stock tracking.

## Features
- Login page and registration page with local user accounts
- Dashboard for adding, editing, removing stock items
- Search, category filter, supplier filter
- Stock status badges for In Stock, Low Stock, Out of Stock
- Local persistence using browser storage

## Run locally

1. Install dependencies

```bash
npm install
```

2. Start the backend server in one terminal

```bash
npm run dev:server
```

3. Start the frontend in another terminal

```bash
npm run dev
```

4. Open the URL shown in the terminal

## Build

```bash
npm run build
```
